## How to run

```
python3 tools/goal_grader.py --dry-run cards/<card>.json     # validate spec shape only (no execution)
python3 tools/goal_grader.py cards/<card>.json <workspace>   # run the sealed grader; prints PASS/FAIL JSON with evidence
```
The grader executes `success_criteria.spec.command` with cwd=`<workspace>`; copy or symlink the card's `assets/gc-NNN/` directory into the workspace so relative asset paths resolve. Exit code 0 = PASS.
